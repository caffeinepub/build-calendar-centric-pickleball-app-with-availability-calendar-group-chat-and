# Specification

## Summary
**Goal:** Update the PWA splash screen to display only the full-screen background image without any logo overlay.

**Planned changes:**
- Remove the logo overlay from the PWA splash screen
- Configure the splash screen to display only the user-provided background image as a full-screen static background
- Use the background image URL from previous conversation context

**User-visible outcome:** When launching the PWA, users will see a clean full-screen background image splash screen without any logo overlay.
